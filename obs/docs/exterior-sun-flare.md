# 外観の恒星フレア調査・試作

2026-10-16。OBSの自由視点「外観」に使用。恒星の方向は船体の主光源に一致させる。

## 参考と判断

- ユーザー提供の3画像：光源周囲の薄い輪、大きな不均一の弧、光源と画面中心を結ぶ方向の小さな反射。
- [Hullinほか、Physically-Based Real-Time Lens Flare Rendering（SIGGRAPH 2011）](https://resources.mpi-inf.mpg.de/lensflareRendering/pdf/flare.pdf)：レンズ内部の反射によるゴースト、絞りによる形状・回折の考え方を参照。
- [Three.js Lensflare](https://threejs.org/docs/pages/Lensflare.html)：光源を追従する複数要素としてのフレア構成を参照。
- [KMZ/ZENITcameraのJupiter-8資料](https://www.zenitcamera.com/archive/lenses/jupiter-8.html)：3群6枚、単層コーティング、9枚羽根の絞りを確認。
- [Jupiter-8の撮影者による逆光作例](https://blog.sunrise-camera.net/selections/%E6%9C%80%E6%96%B0%E3%83%9F%E3%83%A9%E3%83%BC%E3%83%AC%E3%82%B9%E3%82%AB%E3%83%A1%E3%83%A9%E3%81%A7%E4%BD%BF%E3%81%88%E3%82%8B%EF%BC%81%E3%82%AA%E3%83%BC%E3%83%AB%E3%83%89%E3%83%AC%E3%83%B3%E3%82%BA-5/)：開放の柔らかい反射像と、絞った際の絞り形状の現れ方を参照。

現行は光学系の完全な光線追跡ではなく、その特徴を既存のシェーダー内で近似する。

## Jupiter-8を基準にした反射構成

前から1枚・3枚貼り合わせ・2枚貼り合わせの3群6枚。空気とガラスの境界は6面、貼り合わせ面を含む界面は9面。
主な空気境界間の2回反射は15通り、貼り合わせ界面まで含む候補は36通りになる。実際に見える数は反射率・遮蔽・絞り・入射角で変わり、レンズ枚数と可視リング数は一対一には対応しない。

試作はこの界面構成から候補を列挙し、各群内1経路と群間2経路ずつの計9経路を描画する。
それぞれ異なる位置・半径・濃さ・ぼけ幅を持つ、柔らかい円／丸みのある九角形のゴーストを並べる。
9経路はリアルタイム表示用の選択であり「実機では必ず9個見える」という意味ではない。

**確認できた史実と近似値の区別**：群数・枚数・コーティング方式・絞り羽根数は上記資料による。
曲率半径・ガラスの屈折率・面間隔・膜厚を含む当該個体の完全な処方は未取得。
コードの正規化面間隔、残留反射率、反射像の倍率と大きさは作例を参考にした調整値で、実測値や実機の厳密再現として扱わない。

## 試作の仕様

- 色味：現行の暖かな白と淡い金色を維持。参考画像の青・虹色には変更しない。
- 横フレア：中心からレンズ面座標0.09で減衰を始め、0.23で完全に消す。中心の芯は太く、先端ほど細くする。太陽の存在感をロケットのフレアより強めるため、長さと中心の明るさを調整。色味は維持する。
- 内部反射：上記の9経路。画面中心を結ぶ線上で移動し、大小の反射像が異なる濃さで重なる。全周均一な輪にせず、片側の縁と内部の柔らかい光に差を付ける。
- 縦横比：円の距離をアスペクト比で補正し、角度基準で計算。解像度だけでは長さ・形を変えない。
- 遮蔽：船体が恒星を隠すと、反射と眩しさも抑制する。
- 描画：既存のフレア用1パスに統合。リング用の追加画像・描画パスは不要。
- 音声：外観表示中は船内音のマスター音量を即座に0へ固定し、SEとループも停止。船内へ戻る際は元の音声オン／オフ設定を保つ。
