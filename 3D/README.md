# MOONLANDER 3D

既存の MOONLANDER を基にした、ブラウザで遊べる3D月面救出ゲーム。
着陸、探索・エイリアンとの交戦と回避、仲間の護衛、乗船、脱出まで一続きで遊べます。

## 起動

Node.js 24以降を使用します（チェス対戦エンジンの動作要件）。

```sh
npm ci
npm run dev
```

表示されるローカルURLを開いてください。ES Modulesを使うため、HTMLファイルの直接起動では動きません。
配布用の静的ファイルは `npm run build` で `dist/` に生成します。`npm run preview` で配布版を起動できます。
親サイトでは、ルートの `vercel.json` が `/3D/` をこの `dist/` へ振り分けます。

## 船内観察 3D

`/3D/obs.html` は母艦タライロンの遠心重力生活区画を横から見る、独立した船内観察モードです。
船名はともに魚の名前に由来します。母艦はタライロン（Tarairon）、着陸ゲームに登場する着陸船はバラマンディ（Barramundi）。画面や銘板では `TARAIRON` / `BARRAMUNDI` と大文字で表記します。
画面の三層は生活区画の一部分の局所断面であり、母艦全体の姿ではありません。現在の横視点は区画とともに回転する観察視点として扱います。回転半径・回転数・重力の値は未確定で、回転による物理効果の追加実装はまだ行っていません。
中央の梯子は最上階の天井を抜け、回転軸側（上）の連絡通路へ続く断面として表示します。下端は最下層の床で止まります。先の操縦区画・機関室への接続形状は未確定で、移動可能な階は従来の三層のみです。
2D版の `obs.html` はそのまま残し、`js/obs/brain.js` と台詞・設備定義を共有しています。
マイロは白いタンクトップとオリーブドラブの作業パンツ。三毛の船猫とともに船内を移動し、食事・休息・身支度をします。猫の耳は薄い凹面、尻尾は先まで厚みを残した丸い曲面で、休息時には体へ巻き添えます。
マイロの歩行は実際の移動距離に足の周期を合わせ、接地中の足を床に残します。かかとから着地し、つま先で蹴り出し、膝を曲げて足を運びます。移動速度が落ちた場合も足の周期が追従します。
猫は前脚の肘・手首と、後ろ脚の膝・高い位置のかかとを別の構造で動かします。脚の表面は関節に追従する連続した曲面です。歩行は左後脚、左前脚、右後脚、右前脚の四拍で、接地中の足先を床に残し、振り出す足を持ち上げて運びます。肩の前後移動と小さな胴体の上下動を加え、船内の歩行速度を落ち着いた速さに調整しています。壁内への出入りも実際の移動距離に周期を合わせます。
関節構造・接地順は提供された猫の横姿写真と、[猫の四肢歩行研究](https://journals.physiology.org/doi/10.1152/jn.1998.79.4.1687)、[足先軌道の研究](https://pubmed.ncbi.nlm.nih.gov/24899676/)を参考にした描画用の近似です。写真の転載やモーションキャプチャーデータの使用はしていません。

顔は `src/obs/cat-face.js` で頬・鼻梁・口元・顎を一体の曲面にしています。目は眼窩に沿う浅い曲面と毛のあるまぶたで構成し、まばたきでは瞳を縮めず開口部を閉じます。提供された正面写真と[猫カフェMOCHAの公開写真](https://catmocha.jp/en/shop/nagoyaminato/)を比率の参考にしており、写真をテクスチャとして転載したものではありません。

人物や猫を直接クリック／タップすると、その対象へズームして追従します。設備のクリックは行動指示、ドラッグは手動の画面移動です。全景ボタンで追従を解除できます。

猫は各階の壁にある猫穴から壁裏の通路へ入り、別階の穴から出て移動します。ハシゴは使いません。頭から身体、尻尾の順に壁へ隠れ、通路の移動中は姿を見せず、追従カメラだけが出口へ移動します。

毛づくろい中は前脚を舐め、顔を拭き、肩口へ振り向いて舐めます。動かしていない脚は床につけ、尻尾は身体に沿わせます。食後も同じ動作へ入り、給餌・移動の指示で通常姿勢へ戻ります。一時停止中は動作の進行も止まります。

- 全景・マイロ・猫のカメラ選択、拡大縮小、ドラッグによる平行移動。視線は常に横方向。
- クリック・会話で指示した設備は短く点滅し、移動中は琥珀色、使用中は緑、補給不足は赤。設備名と状態も表示し、終了・指示変更時に目印を消去。動きを減らす設定では点滅しません。
- 食事・水は各設備へ直接移動。F（食事）・W（水）・C（猫餌）でも指示できます。
- 食事は左手で器を支え、右手のスプーンで二口食べます。飲水はカップを口元まで運び、縁を唇に当てたまま傾けてから下ろします。手首と指は食器へ追従し、一時停止・動作終了・移動指示に合わせて姿勢も切り替わります。
- 猫の餌皿は下段のキッチンと給水設備の間に配置。給餌指示と空腹時の自律行動は同じ皿へ向かい、到着してから猫餌を1回分消費します。
- 中段右のオーディオ設備を撤去し、船外活動用宇宙服3着を吊るしたラックに変更。ラックの左に船内ハッチ、右端の側壁に船外ハッチを配置し、どちらも船の長手方向に対して直角に取り付けています。船内ハッチは乗員の接近時に背面側へスライドし、通過後に閉鎖します。開ききるまで乗員は手前で待ちます。区画内は船内と同じ気圧で、船外ハッチは常時閉鎖しています。ラックと両ハッチはクリックや会話で点検できます。船外へ出る動作・着替え・減圧は未実装です。下段の補給ハッチとは別設備です。
- 宇宙服ラック左の医療区画には診察ベッド、薬品ロッカー、可動式診察灯、生体モニターを配置。健康時は14秒の健診、怪我・発熱中は24〜36秒の治療になります。クリック、健康警告のボタン、または「治療」「医療区画」で移動。途中で別の指示を出すと中断し、症状は残ります。健診・治療で食料、水分、体力などの欲求を補充することはありません。
- 健康状態は100から始まり、点検や疲労中の移動では左腕の怪我、消耗や不衛生が続くと発熱が発生します。時間経過による体調不良もあります。最初の偶発判定は開始150〜240秒後、同時に複数の症状は発生しません。症状を放置すると健康が低下し、55以下で悪化、30以下で緊急扱いとなります。移動が遅くなり、運動は中止。悪化時には自ら治療を選び、緊急時には他の指示より治療を優先します。健康の下限は5で、死亡・ゲームオーバーはありません。
- 治療中はベッドで処置を受け、モニターの脈拍・体温が落ち着いていきます。怪我の手当て後は左腕に包帯が残ります。完了後180秒は再発しない猶予があり、食事・水分・休養が足りていれば徐々に全快します。一時停止、別タブ、チェス中は健康状態も進行しません。健康・症状は船内状態と同様に再読み込みで初期化されます。数値・症状・回復速度は架空のゲーム用調整であり、医療モデルではありません。
- 冷却設備一基を固定式エアロバイクのジムへ変更。運動ゲージが低下すると自分で運動し、クリックや「運動して」「ジムへ」でも指示できます。運動はゲージを回復し、水分・体力・清潔さを消費します。足とペダル、手とハンドルを同期させて動かします。
- 船内備蓄は食料3回・水4回・猫餌3回分。欠品するとマイロがコンソールで配送を依頼します。配送ボタン／コンソール／会話からの手動発注も可能です。
- コンソールで3秒の送信後、12秒で補給便が到着。ハッチが開き、箱とタンクが荷受け台へ降り、まとめて備蓄を補充します。自然補充や重複発注はありません。送信前の行動変更は発注を取り消し、送信後は配送を継続します。
- 文章入力による会話・行動依頼、HQ通信、日英切り替え、一時停止。
- ゲームへの誘いに応じると、マイロがラウンジへ移動してチェス対戦を開始します。ラウンジ、会話欄の対戦ボタン、「チェスしよう」からも開始できます。プレイヤーが白、マイロが黒。合法手表示、昇格先の選択、キャスリング、アンパッサン、チェック・メイト・引き分け判定、三段階の強さ、手戻し、投了、再戦に対応します。
- 対局中は船内時間と欲求の減少を停止します。盤を閉じると船内生活を再開し、棋譜はブラウザの `barramundi-chess-v1` へ保存。保存キーは船名訂正前のものを互換性のために維持しています。次回は中断局面から再開します。思考は専用の Worker で行い、閉じる・手戻し・再戦時に古い応答を破棄します。
- 船内音は初期状態でオフ。音声ボタンを押すと機械音・足音・通知音を有効化。オーディオ区画の撤去に伴い、ステレオ演奏と音楽設備への行動指示は廃止しています。
- 縦長画面も全体を表示し、人物・猫のカメラで同じ横視点のまま拡大できます。

OBSのエナメル・金属・綿生地・毛並みには、画像生成した材質画像を使用しています（`public/assets/obs/`）。
人物・猫・船室そのものは立体メッシュで、背景画像を貼ったものではありません。
船内の状態変化は保存されず、再読み込み時に初期状態へ戻ります。チェスの対局だけは保存されます（ブラウザの保存機能が利用できない場合を除く）。

チェスのルール判定には `chess.js`（BSD-2-Clause）、相手の思考には `js-chess-engine`（MIT）を使用しています。駒の画像は本プロジェクト内のSVGです。配布用ライセンスは `public/assets/obs/CHESS-LICENSES.txt` に同梱しています。

マイロの頭部には Lee Perry-Smith / Infinite-Realities の3Dスキャン（CC BY 3.0）を使用し、頭部の切り出し・縮尺・肌と短髪の描画を調整しています。出典とライセンスは `public/assets/obs/head/ATTRIBUTION.txt` と同梱ライセンスを参照してください。

## 操作

| 操作 | 着陸中 | 月面 |
| --- | --- | --- |
| WASD / 矢印 | カメラを基準に前後左右移動 | カメラを基準に前後左右移動 |
| SPACE | 逆噴射・上昇 | 離して発射、1.5秒長押しで貫通ビーム |
| SHIFT | 降下を速める | ジャンプ、長押しで高く跳ぶ |
| マウス移動 / 左クリック | 左クリックでも逆噴射 | 照準 / 射撃 |
| E | 着陸後ハシゴを降りる | 全員乗船後、船の近くで脱出 |
| C / 右ドラッグ | 視点切替 / 回転 | 追従・俯瞰切替 / 回転 |
| ESC | 一時停止 | 一時停止 |

ハシゴは S / ↓ で降り、W / ↑ で戻れます。E / SPACEで素早く降下します。
タッチ環境ではスティックとアクションボタンを表示。スティックで向いた方向を基準に照準を補助します。
ウィンドウを離れる、別タブに移動する、操作ガイドを開くと、ミッションは一時停止します。

## 引き継いだルール

- 指定の着陸地点、降下速度1.4m/s以下、傾き±5°以内、横滑り低速で軟着陸。
- 有限の燃料とデブリ衝突。地点外や着陸条件の不成立で失敗。
- 探査車に近づいてクルーを救出。初回2人、周回ごとに1人増加。
- エイリアンは地底から出現して追跡。通常HP3、大型HP10。5体撃破ごとに大型が出現。
- ビーム残量により通常威力1 / 2 / 3。通常消費22、1.5秒の長押しで威力6の貫通攻撃・消費50。
- エネルギーは通常15/秒、船・探査車の近くで90/秒回復。黒筐との接触でも回復。
- 自分または護衛中の仲間が捕まると失敗。乗船待ち・ハシゴを登る間も仲間を護衛。
- 全員乗船後、プレイヤーが船へ戻って脱出。脱出ポッドの上昇演出後に次の周回へ。

3D化にあたり、画面の左右移動を月面上の前後左右移動へ拡張。元のピクセル単位の距離と出現頻度は、3Dの距離・視界に合わせて調整しています。月面の移動範囲には境界があり、射撃にはキーボード・タッチ向けの方向補助があります。

## 検証

```sh
npm test
npm run build
```

着陸・燃料切れ・衝突・射撃・ボス・捕獲・護衛・乗船・脱出・周回・一時停止時の入力解除をテスト。
実際の地形・障害物・敵を使用し、通常の入力だけで着陸から脱出まで進めるシミュレーションも含みます。
デスクトップ表示、モバイル幅、ミッション開始後の3D描画をブラウザで確認済みです。実機のフレームレート測定は未実施です。

対応ブラウザでは `document.modelContext` にミッション状態の読み取りと一時停止・再開を登録します。登録の契約は模擬コンテキストでテスト済みですが、対応ブラウザでのWebMCP実行は未検証です。非対応ブラウザでは登録をスキップし、ゲームは通常どおり動作します。
