# ラウンジのパッド端末

船内備品らしい無骨な業務端末のスタディー。承認された形状を OBS 本編と共用する。

3D ディレクトリで `node studies/pov/server.mjs` を起動し、
<http://127.0.0.1:8772/3D/studies/pad/index.html> を開く。

- 業務端末案と、本編の `createLeisureProps()` で生成する現行端末を切り替える。
- 筐体は 230 × 300 mm。保護材・キーを含めると約 238 × 302 × 39 mm。
- 画面・背面・側面・充電接点の視点、回転・拡大・移動。
- 筐体色、縁の擦れ、画面の明るさと消灯、スタジオ／暗所照明。
- 本編に反映した設定はチャコール `#3d4849`、擦れ 0%、画面の明るさ 85%、点灯。
- 画面は船内記録・ラウンジの選択メニュー・FALL-LINE の読書画面。本編は起動時と手に取るときにランダム選択し、同じ画面を連続で選ばない。
- 操作時と画面サイズ変更時だけ描画。選択した仕上げは保存せず、その場で比較する。

`model.js` は本編の `src/obs/pad-terminal.js` を参照し、`study.js` が比較画面を持つ。
画面の内容・設定は `src/obs/pad-screen.js`。本編用は静止部品を材質ごとにまとめ、同じ形状を共有する。
