# 生活支援ドロイド / 3817

## 軽量版の比較（OBS採用済み）

<http://127.0.0.1:8768/3D/studies/droid/lite.html> で、左に詳細版・右にOBSで使用する軽量版を同じカメラ、照明、姿勢で表示します。左右比較／片方のみ、待機・歩行・ハシゴ・配膳・充電休止、6表情、顔や手元の拡大を切り替えられます。静止中は変更時だけ描画し、非表示タブでは再生も止めます。

船内OBSの充電台は `createDroid({detail:'obs'})` を選択し、待機・移動・生活支援作業で同じ軽量版を使用します。既定の `createDroid()` と形状スタディは詳細版を保持し、比較用に残しています。

- 総三角形数は現行 127,664 → 軽量版 3,042（97.6%減、未使用の表情や非表示トレーを含み、輪郭線を除く）。
- 筒・ケーブルは角材、主要関節は八角形。ひさし、上部の斜め角、脚の3段関節、曲がる指を維持。
- 頭の左右の側面パネルは、現行モデルと同じ前側を斜めに絞った外周にする。中央の関節の周囲に八角形の台座を残し、傷・ビスは画像で表現。
- 胸の黄色い配線は胸の側面まで、赤い配線は腰の外装へ接続して終わらせ、下へはみ出す部分を省く。左右の膝裏の赤い配線は残す。
- バックパックの黒い2本のコードは省き、上下2か所のクランプと金具で背骨の支柱に固定。左右の足先には、平らな甲から前縁へ下がる斜面を付ける。
- 両足のかかとには、足首から斜めに下がるシリンダーをそれぞれ2本残す。現行モデルと同じ取付位置の角材形状で、足の動きに追従する。
- ビス、傷、放熱口、軸受などは512pxの共通画像。顔は1024×512pxの表情画像を1枚の面に表示。黒い目の土台と横向きの口モジュールも画像に含む。
- 本体は部品を1つのSkinnedMeshにまとめ、頂点は各関節に100%固定。形がゴムのように曲がらず、既存のIKとピストン伸縮に追従します。
- トゥーン全身待機の主描画は267 → 3回（本体、顔、輪郭線）。カメラによる見切れや配膳の小物で数値は変わります。影は別です。これは描画回数・形状数の比較であり、船内全体のFPS改善率ではありません。

素材・リグは `src/obs/droid-low.js`、決定的な画像生成は `src/obs/droid-textures.js`。追加ダウンロードは不要です。

確認: `node --test tests/obs-droid-low.test.js tests/obs-droid-study.test.js tests/obs-droid-service.test.js tests/obs-droid-charging.test.js tests/obs-cabin-toon.test.js`。

## 現行モデル

添付された細身の産業用ドロイドの画像を参考にした、独立した3Dスタディ。
船内のコンソール左側に充電台とともに設置済み。待機時は顔の発光と駆動を止め、頭・腰・膝・手首を緩めた充電休止姿勢になります。OBSでは生活支援作業に自動で出発し、終了後に帰還します。

既存のスタディサーバーを利用します。`3D/` で
`node studies/milo/study-server.mjs` を起動し、
<http://127.0.0.1:8768/3D/studies/droid/index.html> を開きます。

- 頭部は幅約30cmの細い外装に、2つの発光管の目と口を配置。
- 通常・喜び・悲しみ・驚き・怒り・眠いの6表情を切り替え。`face=happy` などのURLでも指定可能。
- 目の上に張り出すひさしと左右の斜めの上部パネル。顔は二重の枠・シールの奥に配置。
- 側面は多重リングとボルト付き駆動部、背面は放熱フィンと露出した配線、底面は首取付部とコネクター。
- 外装の細かな傷と継ぎ目、丸い発光管・ソケット・内部の電極線。頭の側面・背面・底面を拡大して確認可能。
- 首を約半分の長さにし、肩の付け根の間隔を約2割縮小。首の支柱・配線も短い形に合わせる。
- 通常時と歩行時の手は手のひらが体側、親指が前を向く。配膳時は手首を回してトレーを保持する。
- 通常時は約7.5度、歩行時は約10度前傾し、顔は少し起こして前を見る。歩行中の肘は約35〜41度曲げ、腕を脚と逆に振る。
- 燻銀、擦れた塗装、銅色の配線。金属／トゥーン／線なし表示を比較。
- 待機、小さな円を巡回する歩行、カップとタオルを載せた配膳トレー。
- 「充電休止」で船内と共通の脱力姿勢を確認。休止中は発光を消し、時間を進めても周囲を見回しません。
- 正面・横・背面・顔・手元の視点と、時間スライダー。
- 腕は固定長の2リンクIK。脚は腿・短い逆関節リンク・すねの3段構造。
- 腿の下の膝と、後ろへ折れる第2関節を個別に動かす。接地中の足はワールド位置に固定。
- 関節間のシリンダーは両端を毎フレーム追従。配膳時は両手の接触点を持ち手に一致させる。

`../../src/obs/droid-model.js` が船内・スタディ共通の形状・材質・リグ・動作、`study.js` が表示と操作を管理します。船内の充電設備・配置は `../../src/obs/droid-charging.js`。
外部の画像・3Dモデルやフォントのダウンロードは不要です。
現行モデルの静止部品は関節ごと・材質ごとにまとめています。

確認: `node --test tests/obs-droid-study.test.js`（`3D/` から）。

## 船内の生活支援

<http://127.0.0.1:8768/3D/studies/droid/service.html> で、OBSと同じ経路・姿勢を作業ごとに確認できます。「次の作業動作へ」で移動を送り、1× / 4× / 12× で全行程を再生できます。確認用の在庫・成熟した野菜はこのスタディだけに用意し、OBSのデータには影響しません。

「歩行を見る」「ハシゴを下る」「ハシゴを上る」で移動中の姿勢を確認できます。時間スライダーと「0.2秒進める」で一時停止しながら確認でき、`time=34.4` のようなURLで再現可能です。ハシゴは実際の横棒の中心に指の握りを合わせ、持ち替える手以外を船内座標に固定します。

- 配送完了後の3種類の物資を補給ハッチから03の倉庫へ運搬。通路を空け、右側へ積みます。配送時に増えた在庫を再加算しません。
- 成熟した野菜を段ごとに収穫。食料庫が満杯なら待機します。
- 02の奥の洗濯室で衣類を集め、ドラム扉を開けて投入、洗濯、取り出し、たたんで収納。
- トイレはブラシ、シャワー室はスポンジで清掃。入室前に扉を開け、退出後に閉めます。
- キッチンで切る・混ぜる・盛り付けの動作。準備した料理は食事で消費するまで鍋を残します。
- 猫餌を倉庫から持ち出して皿に補充。備蓄から1食分を移し、ルーシーが食べる時には二重消費しません。
- 階の移動は中央の梯子。昇降速度は0.40m/s（1フロア約8.5秒）。手の甲をカメラ側、手のひらを横棒側へ向け、手の接地点は昇降中も横棒に固定します。マイロの昇降中は待ち、ドロイドが昇降中はマイロが待ちます。
- 方向転換は片足ずつ持ち上げ、30度以内の小さな踏み替えを繰り返す。接地側の足裏は位置・向きを船内座標に固定し、体の回転だけで床を滑らせない。
- 運搬中は支援物資・洗濯物・野菜トレー・猫餌袋の実際の幅から左右の接触位置を決め、手のひらを側面へ向けて保持。歩行・足踏み旋回・注ぐ動きでも荷物と両手を同じ座標で追従させる。
- 猫餌の補給粒と皿の中身は同じ茶色を使用。
- キッチン左の床置き小物を燻銀のダスト焼却ボックスに置換。倉庫搬入後の空き箱、猫餌の空袋、調理ごみを幅に合わせて持ち運び、扉が開いてから投入します。手を引き、扉を閉じてから琥珀の処理ランプが点灯。処理後は空になって充電台へ戻ります。充填済みの餌は片付け中でもルーシーが食べられます。
- 作業後は充電台へ戻り、少なくとも24秒休止。清掃・洗濯・料理は間隔を空け、物資到着・空の餌皿・収穫を優先します。

確認: `node --test tests/obs-droid-service.test.js tests/obs-droid-charging.test.js tests/obs-droid-study.test.js`。
