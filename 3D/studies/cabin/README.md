# 船内スタディー

2026-09-20に全調整をOBS本編へ反映。船内は輪郭線付きカートゥーンを採用し、全景0pxから拡大時1pxへ滑らかに変化します。人物と猫は1.2px。ここでは本編と共通のコードで3種類を比較できます。

3Dディレクトリで `node studies/cabin/study-server.mjs` を実行し、<http://127.0.0.1:8770/> を開きます。

- 今のver: 現在のOBS船内の材質。
- cartoon ver: 拡散光を三段階に整理し、凹凸・通常の金属反射を省いた材質。船内の輪郭線は全景で0px、全景の2.5倍の拡大で1 CSS px。実際のカメラ倍率に応じて滑らかに変化し、引くと再び細くなる。全景では輪郭線の追加描画を省く。
- cartoon 線なしver: 同じカートゥーン材質で、船内の輪郭線だけを省略。

トゥーンの暗部・中間調を少し明るく調整しています。明部と輪郭線の色は維持し、照明の追加や露出の変更はしていません。

OBSの `ObservationView` で同じ船内モデル・光源・影・描画倍率を使用します。猫・マイロは採用済みトゥーン／髪型A・髭なしを全案で維持。表示板、透明面、濡れた鎖と床の艶を残します。表示切り替えでカメラ・姿勢をリセットしません。

サインは3案共通で NASA Graphics Standards Manual (NHB 1430.2, January 1976) §5.3・6.1・6.2 を参考に整理。指定のHelvetica Mediumに合わせ、ローカルのHelvetica Neue 500を優先し、Helvetica / Arialへフォールバックします。フォントファイルは複製・同梱していません。通常のカーニングと追加字間0em、左揃え、大小文字を使用し、識別略号は保持。白・チャコール・暖色グレーを基本に、船名の赤をアクセントとします。マニュアルは字間の数値を指定しておらず、0emは通常の字間を保つための実装値です。元のサインと変更後は「サイン見本」で比較できます。画面内の計器表示は既存の等幅フォントのままです。

参考: https://www.nasa.gov/wp-content/uploads/2015/01/nasa_graphics_manual_nhb_1430-2_jan_1976.pdf

全景・居住区・キッチン・操縦区・機関の視点、ドラッグ移動、スクロール拡大に対応。初期状態は静止です。「動きを再生」は固定位置の待機動作とファンを進めます。

キッチンの配置は本編の `src/obs/cabin-dressing.js` と共通。キッチンのタオルと掛け棒を省き、ポットと隣のマグの底面を天板上面1.035mに合わせています。

各階の中央はしご右側に赤い消火器を1本ずつ設置。猫用通路の上に壁付けし、ホース・レバー・圧力計を付けています。上部の案内サインはありません。`fire-extinguishers.js` で同じモデルを共有し、既存の静的メッシュ結合に含めます。

操縦区のコンピューター3台の前に操縦席を1脚ずつ配置。参考画像のシェル形状、厚い黒クッション、ヘッドレスト、肘掛け、床固定の関節付き台座を `pilot-seats.js` で作成。外装は燻銀のチタン色、補強部やヒンジは削り出しアルミ色とし、細い切削目・異方性反射を付けています。金属部分はトゥーンでも反射を維持し、輪郭線だけを通常どおり倍率に連動させます。3脚で形状・材質・切削目テクスチャを共有し、静的メッシュ結合に含めています。各マシンの中央に揃え、マシン側へ向けています。

同じ `machined-metals.js` の材質を、ランドリーの洗濯機・乾燥機の外装と全3階の八角形ゲートのビス留め枠にも適用。枠・外装は燻銀、ビス頭と洗濯機の扉縁・ノブ・取っ手は削り出しアルミ色。枠に小さな面取りを付けています。ゴムのシール、操作パネル、衣類は元の材質を維持します。

キッチンのシンクは燻銀、蛇口は少し明るい削り出しアルミ色。同じ切削目と金属反射を共有し、既存の形状・配置を使用します。

ジムの壁掛けダンベル3本にも同じ金属仕上げを適用。両端の重りは燻銀、グリップは削り出しアルミ色としています。

全3階の猫用出入口は、枠・敷居を燻銀、留め具を削り出しアルミ色に統一。開口部の形状、奥の暗部と案内表示は維持しています。

寝台上とダンベル左上の3本の配管パネルは `service-panel.js` で背景を調整。背景は船内の骨組みと同じ黄みを含んだチャコールグレーを維持し、配管は上下の黒っぽい鉄色・中央の赤茶色に戻しています。管・フランジ・留め具には元の材質と汚れテクスチャを使い、基色だけを線形値で1.18倍にしてわずかに明るくしています。光源や形状は追加していません。

カップは `fixture-materials.js` の専用白色陶器材質（汚れマップなし、金属度0、釉薬の反射あり）を使用。野菜は明るい緑とし、既存の3本の栽培灯を白色寄りに調整。葉とアイボリーの棚背面は、RectAreaLightに対応する材質を維持して灯具の光を受けます。追加の光源はありません。

「この視点で負荷比較」は現在のカメラ・時刻・解像度を固定し、各表示25フレームの準備＋100フレームの計測を2巡します。FPS、GPU時間（対応ブラウザのみ）、描画回数を比較します。環境の他の処理やGPUの状態による変動があるため、数値は目安です。

描画・内装・看板の実装は `src/obs/` に移し、このフォルダの各モジュールは再エクスポートしています。本編とスタディーが同じ設定を使用し、配布ビルドにも含まれます。
検証: `node --test studies/cabin/toon-style.test.js`。
