# 生物スタディ

生物の形状、骨格、動作の検討はこのディレクトリにまとめます。
ゲーム本体に組み込む前の確認データも、対象ごとのフォルダで管理します。

- [ルーシー](lucy/README.md): 三毛猫の体型、骨格、歩行、尻尾の形。
- [ルーシーの確認画面](lucy/local/lucy-preview.html): ローカルで生成済みの場合に開けます。
- [宇宙服スタディー](eva/README.md): 本編共通の白・赤の宇宙服、ヘルメット・首・手袋・ブーツの形状確認。起動後は <http://127.0.0.1:8769/>。

調整コードと説明資料はGitで管理します。
元モデルを含む素材、編集ファイル、モデルを埋め込んだ確認HTMLは各スタディの `local/` に置き、
ローカルデータと公開対象を分けます。
