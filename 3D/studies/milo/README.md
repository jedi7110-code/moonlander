# 連続した人物メッシュ

## マイロ・スタディー

リポジトリ内の `3D` で `node studies/milo/study-server.mjs` を実行し、<http://127.0.0.1:8768/> を開きます。正面・背面・左右・斜めの各視点と、静止・歩行・梯子姿勢を切り替え、本編と同じマイロを確認できます。ドラッグ回転、ホイール拡大、時間スライダーにも対応します。

この画面は `src/obs/characters.js` と `src/obs/milo-body.js` を直接使用します。ズボンの常設シワ、前フライ、尻ポケット、カーゴポケット、ブーツを本編と別実装にしません。

### 着席と端末

着席時は参考写真 `images.jpg` のように膝を左右へ開き、足首は元の位置、足裏は水平に保ちます。つま先は少し外向きです。通常の着席・端末・音楽・猫との遊び・コンソールに共通で、立ち上がり／腰掛けには滑らかに連動します。上半身と各動作の手の位置は変更しません。

<http://127.0.0.1:8768/?pose=seat> はラウンジの机に両手を置いた姿勢、<http://127.0.0.1:8768/?pose=tablet> は端末を持つ姿勢を停止して開きます。「腕・手拡大」で、天板への手のひらの接地、端末の背面を支える指、縁に掛かる親指を確認できます。家具・人物・姿勢ともOBS本編の実装を使います。

端末は追加の正面・背面写真を参考に、低い位置で下半分を両手で包み、そろえた指を背面へ添える姿勢です。上体を少し前へ傾け、肘を外へ開き、手首は前腕の延長に保ちます。肩は胴体と一緒に動き、端末へ届かせるために腕だけを伸縮しません。端末用の複製メッシュだけで指の開きと指関節への追従を補正し、他の動作では元の形に戻します。「端末・横から」「端末・画面側」で手首の連続性と、縁の親指・背面の指を確認できます。

### 診察台と表面走査

<http://127.0.0.1:8768/?pose=medical> で診察中の12秒地点を停止して開きます。本編と共通の診察姿勢・台・走査装置を使い、両手を体の脇で台に置く姿勢と、新しい人体メッシュの表面を追う緑ラインを確認できます。再生・時間スライダーで乗降と走査、正面・斜めで手の接地を確認します。睡眠時のお腹に手を置く姿勢、梯子動作とは独立です。

### ハシゴ動作（本編共通）

<http://127.0.0.1:8768/?pose=ladder> で「梯子・本編」を斜め横・0.5倍再生で開きます。左右の側面、正面、ドラッグ回転、0.25倍、時間スライダー、上る／下りる、接触点の表示を切り替えられます。「梯子・従来」は旧動作の比較用です。

参考はユーザー提供の `download-1.jpg` と `download.jpg`。上側の手を顔より高い段へ伸ばす、下側の肘を曲げる、片膝を前へ持ち上げる、支持脚を伸ばす姿勢を参考にしています。写真は静止画のため、掛け替えの順番と速度は試作上の設定です。船内に合わせて垂直・幅72cm・段間隔28cmとし、右足→左手→左足→右手の順に一つずつ動かします。先に足の支持を上げてから反対の手を伸ばすことで、上下に開きすぎた姿勢を避けます。掴んでいる手と支持足は段に固定し、離した時だけ引いて次の段へ運びます。

スタディーはマイロを追従する座標系で、4秒で左右一巡・56cm上昇します。本編は `src/obs/ladder-pose.js` と `src/obs/ladder-hand-fit.js` の同じ姿勢を使い、`cabin-ladder.js` で実際の高さに同期します。段の基準高12cm・間隔28cm・奥行3cmに手足が合い、下降は同じ軌道を逆にたどります。本編の移動速度・生活サイクルは維持し、実移動56cmごとに左右一巡します。停止中は位相も停止し、階床の前後42cmでは歩行と昇降を補間します。研究画面側の旧ファイル名は共通実装への再エクスポートです。

腕は梯子専用の二関節計算で、肘を手首より下に保ちます。手が肩の高さを越えても肩の回転方向を反転させず、肘は一軸だけで曲げます。手首は段の少し下・手前に置き、指を上へ向けて掛けます。掛け替え時の手の引き量は3.5cmに抑え、体へ引き込みすぎて腕を折り畳まないようにしています。

体は手足の長さから届く範囲を計算して梯子から引き、腰の高さも同時に合わせます。膝はわずかに外側へ向けつつ前へ曲げ、背面で横に張り出す姿勢を避けます。肘も各肩の幅に近い位置を保ち、胸の中央へ折り込まないようにしています。腕・膝・胴の実スキン表面について、一周期を60fpsでサンプリングし、段と左右支柱から5mm以上離れることを回帰テストしています（接触させる手・靴は除外）。背面の膝の横開き・肘の内折れにも回帰テストがあります。

握りは手首の固定オフセットだけでなく、段が指の内側へ入る位置から決めます。`ladder-hand-fit.js` は昇降用に複製したメッシュだけを使い、取り込み元の長い指と広い指間隔をリグに合わせ、手首から前腕の断面も整えます。指ごとに曲げ角を変え、握った際の皮膚の段への食い込みは接触形状補正で逃がします。補正は手を開くと解除され、他の姿勢では元のメッシュへ戻ります。元アセットは変更しません。「左手・握り拡大」「右手・握り拡大」で個別に確認できます。実スキンの全指・掌・親指の接触、手首の断面厚、途中の時刻から再生した場合の再現性、元メッシュの復帰もテストしています。

時計のベルトもスタディーの手首断面に合わせ、浮かないよう位置と楕円断面を追従させます。他の姿勢へ戻すと元の位置・ベルト形状を復元します。

`node --test tests/obs-ladder-study.test.js` で三点支持、段との接触、実人体リグの手首・靴底の位置、周期の連続性、肩を引き伸ばさないことに加え、上り下り二周期で肩・手首が反転しないこと、肘・手首の過度な屈曲がないことを確認します。

ユーザー提供の `fdx54mtvuz28-FinalBaseMesh.rar` 内の `FinalBaseMesh.obj` を使用。球や筒を関節で重ねる従来の体から、肩・肘・手首・骨盤・膝が共有頂点でつながる一つのスキンメッシュへ置き換えています。宇宙服には影響しません。

## 再生成

### 歩行の比較

#### キャラクター別の使い分け

- マイロの通常歩行は「歩行・実測」を使用します。
- 船内アンドロイドには「歩行・従来」を使用する方針です。アンドロイド本体は未実装ですが、`src/obs/walking.js` の `applyWalkingPose(root, distance)` と、その回帰テストは削除せず保持します。適用先には既存の人物リグと互換性のある関節構成が必要です。
- スタディーの「歩行・従来」は確認用として残します。既存の人物制御では `walkStyle: 'legacy'` で選択できます。

初期表示の「歩行・実測」は、ユーザー提供の `Walk_Card_noStops_Take001.bvh` から直進中の26.56〜27.68秒を取り出した1.12秒のループです。「歩行・従来」と同じ人物で比較できます。実測の腰・肩の回転、左右の腕振り、膝の向きをリターゲットし、足の接地を既存の脚長とブーツの寸法に合わせます。OBSの通常歩行にも同じ実装を使用し、実移動距離で位相を進めます。梯子・飲食などの専用動作は維持します。

`src/obs/milo-walk-cycle.json` は68フレームの関節位置だけを保持します。BVH全編・動画・Unityパッケージは同梱しません。並進を除去し、端点の差を補正して周期補間します。元ファイル名、SHA-256、採用区間はJSONに記録しています。

```sh
node studies/milo/build-walk.mjs /path/to/Walk_Card_noStops_Take001.bvh
node --test tests/obs-mocap-study.test.js
```

この書き出しスクリプトは、このBVHの骨名・Z上方向・直進区間専用です。別クリップ用の汎用変換ではありません。ユーザーの承認によりOBSへ採用していますが、参照ファイルの利用・再配布条件の確認は別途必要です。

### 人体メッシュ

```sh
node studies/milo/build-body.mjs /path/to/FinalBaseMesh.obj public/assets/obs/milo/body.json
```

元OBJは変更しません。原本のAポーズを既存の腕・脚の長さに合わせ、最大4ウェイトを45個の関節へ割り当てます（手首の回転補助4個を含む）。実行時に左右の親指IP関節を追加し、計47個になります。指は通常時の緩い曲がりと、既存の握り動作に追従します。骨盤の中央を左右の太腿へ別々に追従させると歩行時に伸びるため、中央は骨盤へ固定し、外側へ滑らかに配分します。

切断面は既存の顔に重なる首元とブーツ内の足首だけです。胴と手足の間には切断面を作りません。トポロジーの接続と、歩行・着席・梯子・飲食時の変形は `tests/obs-milo-body.test.js` で検証します。

元人体の顎下面は首内へ収め、スキャン顔との干渉を防ぎます。顔側は `headGeometry()` で切断面を横切る三角形を平面上で分割し、首を襟の内側まで延長します。三角形ごとの削除による顎下のギザギザを再発させないため、首側面に開いた境界が残らないこともテストしています。

見える首の太さは顔側で保持します。人体側の顎残片を細く隠す処理とは分離し、うなじの絞りを弱めて首の横幅・前後の厚みを確保。襟元は少し広がる形とし、断面寸法もテストで検証します。

手首は手の向きを90度合わせる際の線形スキニングで断面が潰れないよう、実際の「手のひらを内向きにした姿勢」で厚みを成形してから逆変換しています。左右それぞれ2個の補助関節で手の回転を段階的に伝え、大きく返したときの潰れも抑えます。前腕から手の付け根へ滑らかに太さをつなぎ、静止・歩行・梯子・着席・飲食時にも断面が薄い帯にならないことを検証します。

顔、髪、ブーツ、小物、既存の動作制御は維持。上着は半袖・丸首のTシャツです。胸の凹凸をならして胴にゆとりを持たせ、袖も腕から少し浮かせた輪郭にしています。襟と袖口には細い縁を描画します。服とズボンの色は連続した表面に描画し、動作中も同じウェイトで変形します。ズボンは人体への単純な膨張ではなく、腰・太腿・膝・ふくらはぎのゆとりを定義した断面へ成形します。股まわりの人体の凹凸をならし、膝を絞らない作業ズボンに変更。広げた股まわりはウェイトも隣接頂点へならし、片脚を上げた際の引きつりを抑えます。ポケットは広げた太腿に合わせて外側へ移動しています。

`loadMiloBody()` が表示データを読み込み、`attachMiloBody()` が従来の関節グループに骨を接続します。独立した旧人体パーツは非表示です。非ブラウザの既存動作テストは、アセットを読み込まない場合に従来の形状を使います。実アセットを使う検証を別途必ず実行してください。

## 元データの条件

提供RARにはOBJのみが含まれ、利用条件・作者情報・材質ファイルは同梱されていません。別の Male Mannequin フォルダにある Creazilla の条件を、このOBJへ流用しないでください。公開配布時には、このOBJの取得元と利用条件を確認してください。
