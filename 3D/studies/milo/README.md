# 連続した人物メッシュ

## マイロ・スタディー

リポジトリ内の `3D` で `node studies/milo/study-server.mjs` を実行し、<http://127.0.0.1:8768/> を開きます。正面・背面・左右・斜めの各視点と、静止・歩行・梯子姿勢を切り替え、本編と同じマイロを確認できます。ドラッグ回転、ホイール拡大、時間スライダーにも対応します。

この画面は `src/obs/characters.js` と `src/obs/milo-body.js` を直接使用します。ズボンの常設シワ、前フライ、尻ポケット、カーゴポケット、ブーツを本編と別実装にしません。

ユーザー提供の `fdx54mtvuz28-FinalBaseMesh.rar` 内の `FinalBaseMesh.obj` を使用。球や筒を関節で重ねる従来の体から、肩・肘・手首・骨盤・膝が共有頂点でつながる一つのスキンメッシュへ置き換えています。宇宙服には影響しません。

## 再生成

### 歩行の比較

初期表示の「歩行・実測」は、ユーザー提供の `Walk_Card_noStops_Take001.bvh` から直進中の26.56〜27.68秒を取り出した1.12秒のループです。「歩行・従来」と同じ人物で比較できます。実測の腰・肩の回転、左右の腕振り、膝の向きをリターゲットし、足の接地を既存の脚長とブーツの寸法に合わせます。OBSの通常歩行にも同じ実装を使用し、実移動距離で位相を進めます。梯子・飲食などの専用動作は維持します。

`src/obs/milo-walk-cycle.json` は68フレームの関節位置だけを保持します。BVH全編・動画・Unityパッケージは同梱しません。並進を除去し、端点の差を補正して周期補間します。元ファイル名、SHA-256、採用区間はJSONに記録しています。

```sh
node studies/milo/build-walk.mjs /path/to/Walk_Card_noStops_Take001.bvh
node --test tests/obs-mocap-study.test.js
```

この書き出しスクリプトは、このBVHの骨名・Z上方向・直進区間専用です。別クリップ用の汎用変換ではありません。ユーザーの承認によりOBSへ採用していますが、参照ファイルの利用・再配布条件の確認は別途必要です。

### 人体メッシュ

```sh
node studies/milo/build-body.mjs /path/to/FinalBaseMesh.obj public/assets/obs/milo/body.json
```

元OBJは変更しません。原本のAポーズを既存の腕・脚の長さに合わせ、最大4ウェイトを45個の関節へ割り当てます（手首の回転補助4個を含む）。実行時に左右の親指IP関節を追加し、計47個になります。指は通常時の緩い曲がりと、既存の握り動作に追従します。骨盤の中央を左右の太腿へ別々に追従させると歩行時に伸びるため、中央は骨盤へ固定し、外側へ滑らかに配分します。

切断面は既存の顔に重なる首元とブーツ内の足首だけです。胴と手足の間には切断面を作りません。トポロジーの接続と、歩行・着席・梯子・飲食時の変形は `tests/obs-milo-body.test.js` で検証します。

元人体の顎下面は首内へ収め、スキャン顔との干渉を防ぎます。顔側は `headGeometry()` で切断面を横切る三角形を平面上で分割し、首を襟の内側まで延長します。三角形ごとの削除による顎下のギザギザを再発させないため、首側面に開いた境界が残らないこともテストしています。

見える首の太さは顔側で保持します。人体側の顎残片を細く隠す処理とは分離し、うなじの絞りを弱めて首の横幅・前後の厚みを確保。襟元は少し広がる形とし、断面寸法もテストで検証します。

手首は手の向きを90度合わせる際の線形スキニングで断面が潰れないよう、実際の「手のひらを内向きにした姿勢」で厚みを成形してから逆変換しています。左右それぞれ2個の補助関節で手の回転を段階的に伝え、大きく返したときの潰れも抑えます。前腕から手の付け根へ滑らかに太さをつなぎ、静止・歩行・梯子・着席・飲食時にも断面が薄い帯にならないことを検証します。

顔、髪、ブーツ、小物、既存の動作制御は維持。上着は半袖・丸首のTシャツです。胸の凹凸をならして胴にゆとりを持たせ、袖も腕から少し浮かせた輪郭にしています。襟と袖口には細い縁を描画します。服とズボンの色は連続した表面に描画し、動作中も同じウェイトで変形します。ズボンは人体への単純な膨張ではなく、腰・太腿・膝・ふくらはぎのゆとりを定義した断面へ成形します。股まわりの人体の凹凸をならし、膝を絞らない作業ズボンに変更。広げた股まわりはウェイトも隣接頂点へならし、片脚を上げた際の引きつりを抑えます。ポケットは広げた太腿に合わせて外側へ移動しています。

`loadMiloBody()` が表示データを読み込み、`attachMiloBody()` が従来の関節グループに骨を接続します。独立した旧人体パーツは非表示です。非ブラウザの既存動作テストは、アセットを読み込まない場合に従来の形状を使います。実アセットを使う検証を別途必ず実行してください。

## 元データの条件

提供RARにはOBJのみが含まれ、利用条件・作者情報・材質ファイルは同梱されていません。別の Male Mannequin フォルダにある Creazilla の条件を、このOBJへ流用しないでください。公開配布時には、このOBJの取得元と利用条件を確認してください。
