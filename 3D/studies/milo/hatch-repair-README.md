# 船内ハッチ修理スタディー

Vite 起動後、`/3D/hatch-repair-study.html` を開く。既存の `npm run build` にも含まれる。

- **現行 / OBS** は実際の `HatchRepairVisit` と `animateMilo` を使用する。
- 再生範囲、0.1〜1倍速、停止、1/60秒のコマ送り、全工程の時間スライダー。
- 手元・真横・扉側・全身。ドラッグで自由回転。扉側は手の観察用に扉だけを隠す。
- 関節ガイドと、実際の工具先端〜ネジの距離（接触中のみ）を表示。
- **調整案** はこのページ限定。手首の振れ幅、往復速度、手を伸ばす時間、肘の切り替え補正を比較する。
- **この状態のURLをコピー** で時刻・カメラ座標・調整値を保存して再現できる。再生は停止状態で復元する。

## 扉デザインの統合

OBS・扉デザインスタディー・この修理スタディーは、`createEVAHatch` → `createPressureHatch` の同じ扉を使用する。中央分割で左右の壁内へ収納するアイボリー仕上げ、角度を合わせた窓、表裏のロック、厚い外周と枠の重なりを共通化している。金属仕上げ案は採用していない。

ロックの修理位置は扉モデルの寸法から計算する。OBSの階高・アニメーション用の親への付け替えを含め、実際のネジの先端と実際のドライバー先端を比較する統合テストで接触を確認する。

合体確認: `/3D/hatch-repair-study.html?time=11.8&mode=current&view=wide&door=1`。扉の統合とモーション調整案の採用は別で、後者は引き続きスタディー内だけ。

## 現状の確認

腕のIKは手首位置を連続的に移動させる一方、reach がゼロから非ゼロになる瞬間に肩・肘の回転面が約32度変わる。現行モーションを再現するテストと、スタディー限定の補正を比較するテストを追加している。

調整案では、手が低い位置にある範囲でニュートラル姿勢とIK姿勢を滑らかに補間する。完全に伸ばした際の工具接触位置は変更しない。既存OBSの修理コードには補正を反映していない。採用する設定を決めてから共有モーション側へ移す。

## ドライバーの握り

握りはOBS・スタディー共通。8.968秒のような腕を上げ始めた時刻でも、柄を手のひらに横向きに収め、四本指を曲げて親指を柄に沿わせる。握る強さは腕の伸び量と連動させず、工具が出ている間は維持する。点検の終わりに指を閉じ、工具をしまった後に開く。取り込んだ指の長さに合わせて各関節を個別調整し、指の実メッシュと柄の接触・修理中の工具先端位置をテストしている。

実装: `src/hatch-repair-study-model.js`, `src/hatch-repair-study.js`, `src/hatch-repair-study.html`。
確認: `node --test tests/obs-hatch-repair-study.test.js tests/obs-hatch-repair-grip.test.js tests/obs-environment.test.js`。
