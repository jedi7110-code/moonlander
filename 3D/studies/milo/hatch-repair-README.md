# 船内ハッチ修理スタディー

Vite 起動後、`/3D/hatch-repair-study.html` を開く。既存の `npm run build` にも含まれる。

- **現行 / OBS** は実際の `HatchRepairVisit` と `animateMilo` を使用する。
- 再生範囲、0.1〜1倍速、停止、1/60秒のコマ送り、全工程の時間スライダー。
- 手元・真横・扉側・全身。ドラッグで自由回転。扉側は手の観察用に扉だけを隠す。
- **握り・甲側 / 握り・掌側** は、実際の手の座標を中心に拡大する。親指の対向、柄を包む四本の指、掌との接触を両側から確認できる。扉は自動で隠す。
- 関節ガイドと、実際の工具先端〜ネジの距離（接触中のみ）を表示。
- **調整案** はこのページ限定。手首の振れ幅、往復速度、手を伸ばす時間を比較する。腕と手首の連続動作はOBS共通。
- **この状態のURLをコピー** で時刻・カメラ座標・調整値を保存して再現できる。再生は停止状態で復元する。

## 扉デザインの統合

OBS・扉デザインスタディー・この修理スタディーは、`createEVAHatch` → `createPressureHatch` の同じ扉を使用する。中央分割で左右の壁内へ収納するアイボリー仕上げ、角度を合わせた窓、表裏のロック、厚い外周と枠の重なりを共通化している。金属仕上げ案は採用していない。

ロックの修理位置は扉モデルの寸法から計算する。OBSの階高・アニメーション用の親への付け替えを含め、実際のネジの先端と実際のドライバー先端を比較する統合テストで接触を確認する。

合体確認: `/3D/hatch-repair-study.html?time=11.8&mode=current&view=wide&door=1`。速度・振れ幅の追加調整は引き続きスタディー内だけ。

## 腕・手首の連続動作

OBS・スタディーで同じ修正済みモーションを使う。肩・肘・手首の実際のオフセットを解くIKに変更し、肘の回転面をニュートラルから連続的に移す。従来の伸ばし始めの約32度の切り替わりを解消した。

腕を上げる固定の回転経路を補間した後で、工具の小さな反復回転を加える。180度の境目で最短回転の経路が逆転し、手首が突然反転する問題を防ぐ。手首の折れは最大0.72radに制限。工具を掌に斜めに収めることで、作業中も無理に手首を折らず、実際の工具先端とネジの接触を維持する。

工具を持たない手は体の横で自然に休める。扉に届かないまま宙で手首だけを下げていた、以前の部分的な支え動作は使わない。

点検・修理・確認と、各工程からの中断について、1/60秒ごとの肩・肘・手首の位置と回転、指の開閉の連続性、逆順シークの再現性を検証する。中断時も握りを維持してから工具をしまい、最後に指を開く。

## ドライバーの握り

### 写真と資料からの観察基準

ユーザー提供のレンチを握る写真（2026-10-11）では、柄を掌の中に収め、四本の指を内側へ曲げ、親指で反対側から押さえる。指先だけで柄をつままず、手首から前腕へ連続する輪郭を保つ。人差し指から小指へ指の長さが変わるため、全指に同じ関節角を適用しない。親指の付け根を移動して接触を作らない。

[CCOHS: Hand Tool Ergonomics — Tool Design](https://www.ccohs.ca/oshanswers/ergonomics/handtools/tooldesign.html) は、全体で包む power grip と、親指・指でつまむ pinch grip を区別し、工具に合わせた握りと手首の過度な屈曲の回避を説明している。参考写真は包む握りの基準に使い、ドライバーの回転軸やネジの位置は現在の実モデルから合わせる。

実装上は、掌に斜めに柄を収め、親指を対向させる。作業中の肘は肩より低くし、前腕と握りの回転を一緒に調整する。指の実メッシュについて、全五指が柄に接触すること、親指の接触面が四指の接触面と対向すること、柄の芯を通り抜けないことを確認する。工具の先端接触、手の甲が外向きであること、動作・中断の連続性も共通テストで確認する。

拡大確認で、横座標による関節割り当てが一つの指を複数の指の関節へ振り分け、表面を尖らせていたことを確認した。修理専用の `repair-hand-fit.js` は元メッシュの五つの指先の接続成分から掌へラベルを広げ、各指の表面を自分の関節で曲げる。親指の先端は thumbIP に配分し、付け根だけが回って先端が棒状に残る問題も修正。カップ・食事・端末などの既存の握りは従来のフィットを使う。

物ごとに把持を分ける。ドライバー・レンチは柄を包む握り。タバコは細い軸を二指で保持し、同じ拳形を流用しない。ライターは本体を掌と指で支えながら親指を操作に使う。カップは取っ手の支持であり、工具の握りをそのまま移植しない。

握りはOBS・スタディー共通。8.968秒のような腕を上げ始めた時刻でも、柄を掌に斜めに収め、指と親指で保持する。親指は付け根を移動させず、関節の回転で対向させる。握る強さは腕の伸び量と連動させず、工具が出ている間は維持する。点検の終わりに指を閉じ、工具をしまった後に開く。取り込んだ指の長さに合わせて各関節を個別調整し、指の実メッシュと実際の斜めの柄の接触・修理中の工具先端位置をテストしている。
