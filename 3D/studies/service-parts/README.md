# OBS 船内パーツ壁面スタディー

現行の横長の壁面パーツを、同じ設置範囲で置き換える3案の形状スタディーです。

1. 整備カセット: 面一の扉と小さな引き手。
2. 部品収納ラック: 3個の密閉カートリッジ。
3. 配管点検パネル: 露出した配管、バルブ、点検板。

`npm run dev` の後、`http://127.0.0.1:5173/3D/service-parts-study.html` を開きます。比較表示と各案の拡大表示を切り替え、ドラッグで角度を変えられます。`preview.jpg` は比較表示の記録です。

素材はOBSの船内素材を読み込みます。採用配置はベッド上が01、ジム上が03、灰皿上が02、ラウンジのソファ上が02です。ラウンジの旧照明スイッチは撤去しました。OBS本体もこの共通モデルを読み込みます。`obs-ashtray-bed.jpg`、`obs-gym.jpg`、`obs-lounge.jpg` は船内での表示確認です。

ジムの03パネルとダンベル壁掛け板は右端を揃えています。`obs-gym-aligned.jpg` で位置を確認できます。

ベッド上の01パネルは縮小し、`obs-bed-reduced.jpg` で見え方を確認できます。
