# OBS — 彼らの目線

マイロ、ルーシー、3817 の目から船内を見る独立サンプル。
キャラは従来の船内行動を続け、見回す入力を実際の頭部の動きに重ねる。

## 起動

`3D` ディレクトリで `node studies/pov/server.mjs` を実行し、
http://127.0.0.1:8772/3D/studies/pov/index.html を開く。
ポートは `POV_PORT`、待ち受け先は `POV_HOST` で変更できる。
同じ Wi-Fi のスマホで試す場合は `POV_HOST=0.0.0.0` で起動し、
Mac の LAN アドレスのポート 8772 を開く。

## 操作

- 上のボタンでキャラの本人視点／全景を切り替える。
- PC は画面内のマウス位置、スマホはスワイプで見回す。
- 「外から首を見る」で、首の実際の動きを確認できる。
- 「正面に戻す」または R で首を戻し、Esc で全景へ戻る。
- 「移動を試す」で歩行を開始する。3817 は給餌へ向かう。
- マイロの「ベッドで眠る」で就寝、「起きる」で起床する。
- 「一時停止」は船内の行動を止める。見回す操作は引き続き可能。
- 「床色」で濃いグレー／濃いブラウンの金属床を比較できる。

## 試作の範囲

本人視点だけ手前の壁の内張りを表示する。既存の船内と材質・パネル寸法を共有し、
宇宙服側と船外側の扉から手前の壁まで隔壁をつなぐ。
マイロのカメラは歩行時の上下動や頭の傾きを受けず、水平を保つ。
通常の視点は目の位置から進行方向へ 4 cm だけ前に出し、胸や肩は見えるままにする。
ハシゴでは前方への補正を外し、実際の頭の位置に追従して段を突き抜けないようにする。
`?character=milo&area=ladder` は昇降の途中から静止して確認できる。
座るなどの姿勢変化では高さを滑らかに追従する。首のアニメーションは従来通り残る。
本人視点の頭部だけ描画を抑え、外からの表示や鏡・影では頭部を維持する。
扉まわりから開始する確認用 URL は
http://127.0.0.1:8772/3D/studies/pov/index.html?character=milo&area=airlock 。
ラウンジテーブルの小物を確認する URL は
http://127.0.0.1:8772/3D/studies/pov/index.html?character=milo&area=lounge 。
取っ手付きの中空カップにコーヒーを入れ、パッド端末・ヘッドホン・猫じゃらしを卓上に配置する。
マイロが使う小物は卓上側を隠し、使い終えると戻す。
水飲みカップは `area=water` で確認できる。水位・透明な液面の反射・水際を表示し、
飲むときも液面が消えず、カップ内で水平を保つ。
キャラ別の左右／上下制限は `look.js` の試作値で、解剖学的な測定値ではない。
睡眠や作業などの姿勢では見回す範囲を抑える。
ベッドでは全景と同じ頭の位置・向きに視点を付け、座る、体を回して倒す、寝台に収まる動作をそのまま追う。
完全に横になった後、約 3 秒かけて上下のまぶたを閉じて暗くする。
起床時にまぶたを開き、体を起こした後に見回す操作へ戻る。一時停止中は開閉も止まる。
暗転はマイロの本人視点のみ。確認用の `?character=milo&area=bunk` はベッドの前に立った状態から始まり、「再生」で一連の動作が進む。
この URL に `&sleep=closing` を追加すると、まぶたを半分閉じた状態で静止して確認できる。
`&sleep=lowering` は体を倒す途中で静止し、本人視点と外からの表示を同じ姿勢で比較できる。
OBSにもキャラ別の本人視点と見回す操作を組み込み、首の制御・カメラの安定化・就寝／治療・手前の壁は `src/obs/first-person-*.js` と `viewing-wall.js` を共有する。VR入力は従来の観察操作を維持する。

床は参考画像に合わせた金属のサービスパネルと枠付き格子。
格子は当初の縦横 1/3 に縮め、格子付きパネルの手前と奥に 1 つずつ配置する。
初期色は濃いブラウン。床色メニューで濃いグレーにも切り替えられる。
桟は床面より 2 mm 下、格子の受け皿は 72 mm 下に設け、平面に模様を貼るだけの構造にはしていない。
木目状の長い筋と旧来の床端の横桟を置き換え、床の高さ・ハシゴ開口・手前の橋は維持する。
上 2 層の歩行線はハシゴ前で手前の橋へ滑らかに回り込み、開口の上を横切らない。
この歩行線とハシゴへの接続は共通の船内表示にも適用する。
床の生成は `src/obs/metal-deck.js` をOBSと共有し、通常のOBSも同じ濃いブラウンの金属床を使う。
足元灯は手前の壁のパネル下端と巾木の間に設け、光源を壁面から約 4 cm 奥へ埋め込む。
壁際 60 cm の床への柔らかな光は床材のシェーダーで表現し、全景／外からの確認では壁とともに消える。

PC ブラウザで 3 キャラの視点・首の動き・全景復帰を確認。
390 × 844 の画面幅も確認済み。スマホ実機のタッチ操作は未確認。

`node --test tests/obs-pov-study.test.js` で入力制限、首の付け根の保持、
回転の累積防止、骨の軸変換、歩行視点の安定、カメラ別の頭部表示、
隔壁の隙間と扉の開口を検証できる。
`node --test tests/obs-pov-metal-deck.test.js` は格子の深さ、足元の高さ、
ハシゴ開口、旧横桟の除去、床色の切り替えを検証する。
`node --test tests/obs-cabin-walkway.test.js` は左右両方向のブーツの接地範囲とハシゴへの接続を検証する。
