# カーティス：全身変貌スタディー

2026-11-26作成、2026-11-27に全身への変貌を追加。既存のOBS用カーティスモデルを読み込み、右腕から全身へ変わっていく様子を検討する独立した3Dプレビュー。

## 起動

`3D` ディレクトリから実行する。

```sh
node ../obs/node_modules/vite/bin/vite.js --config studies/curtis-infection/vite.config.mjs --configLoader native
```

http://127.0.0.1:5186/studies/curtis-infection/index.html

隣接する `obs` のインストール済みThree.js/Vite、キャラクター生成コード、`public` 内のアセットを参照する。既存のカーティスや本編コードは変更しない。

## 操作・検討内容

- 「通常」「異変」「伸長」「片腕変貌」「全身へ侵食」「全身変貌」のプリセットと、進行度スライダー。
- 通常時から右前腕に重ね巻きの包帯。月面でエイリアンに負傷させられた設定。腕の膨張に合わせて巻き目が開き、布が裂けて外れる。通常へ戻すと包帯も復元する。
- 包帯は現在の皮膚・筋肉・甲殻の断面に合わせて全周を覆う。非対称な前腕の中心ずれと手首の捻りに追従し、皮膚より外側に布の厚み・重ね巻きの縁を確保。「腕に寄る」はその時点の右前腕を中心に拡大する。
- 通常から片腕変貌まで12秒、その先の全身変貌まで12秒の再生、一時停止、通常への復帰。全身変貌から再生すると片腕変貌から始まる。
- 「歩行を見る」で全身変貌に切り替わり、低い姿勢のナックルウォークをその場で再生。1周期1.85秒、拳と足を時間差で持ち上げ、肩・骨盤に左右の揺れを加える。停止、姿勢や変貌段階の変更で静止に戻る。
- 接地姿勢では股関節から膝を外へ開き、左右の足首の間隔を全身変貌時に約55cmまで広げる。足先は外向き約10度。歩行中も左右別々の幅を保ち、太くなった脚と足指がくっつかないようにする。
- 拳の接地点を前方・外側へ置き、肘の曲がる向きも前外側へ変更。肘と膝が同じ位置に重ならないよう、静止・歩行の腕と脚を分離する。
- 内部の進行値は0〜2。以前の姿は値1（画面では50%）でそのまま比較できる。初期表示は全身変貌。
- 「前屈みで手を床につく」（初期表示）、「腕を見つめる」「腕を伸ばす」の姿勢切り替え。
- 正面、側面、背面、腕・顔への接近、ドラッグでの回転と拡大。「顔に寄る」は進行度に合わせて頭の位置を追う。
- 肘下の伸長、掌と指の伸長・屈曲、皮膚の変色と筋状の隆起。
- 改訂版：肘そのものを下方13cm・外側4.5cm・後方4.5cmへ段階的に移動。肘の補助骨も同じ位置へ移動し、移動後の関節を支点に曲げる。
- 右腕（正面から見て画面左側）の前腕に筋肉状の量感と硬い節を追加。大きすぎるという指摘を受け、前腕の最大半径を19cmから10.5cm、前腕の追加伸長を56cmから28cmに縮小。掌・指の拡大も抑制。
- 尖った鉤爪を廃止し、短く丸い爪へ変更。丸い指先を維持する。
- 右腕の重さに引かれ、背骨から右側へ最大約18度傾く。肩・頭・腕を同じ背骨の曲線に追従させ、足と骨盤は元の位置を維持する。首の接続も姿勢に合わせて補正。
- 接地姿勢では腰を折り、骨盤を32cm下げ、両膝を前へ曲げる。変化後の腕の長さで関節を解き、右手と両足を床に接地させる。掌の厚みも含む接地補正、シャツ裾の追従、足元の影を追加。
- 2026-11-27の最新指示：手は下向きに変更。指を丸め、ゴリラのように拳側で支える。腰・膝の曲がりと丸い指先を維持。
- 全身への侵食：右肩・背中・胴から左腕・両脚へ、隆起した灰緑色の皮膚が広がる。肩には凹凸のある甲殻、肩甲骨には重なる板、背骨には8節の甲殻とトゲを追加。各部位の骨格に追従して成長する。指先の丸い爪は維持。
- 服の破れ：アロハ・裾・下のTシャツ・ズボンを布片に分け、体の膨張→裂け目→めくれ→落下の順に動かす。変貌の進行度で再現でき、逆戻しで元の服に復帰。全身変貌時は布片が残らない。
- 両腕の伸長：全身への侵食に合わせて左肘も移動し、右腕と同量の前腕・掌・指の伸長を追加。接地姿勢ではさらに骨盤を2.5cm下げ、両拳が床に届くよう補正する。爪は丸いまま。
- 足の変貌に合わせてブーツ本体・靴底・紐・金具を隠す。踵・土踏まず・甲・足首・4本の指を連続した皮膚で造形し、甲の腱、皺、重なる小甲殻、指の節、短く丸い爪を追加。「足に寄る」で接近確認できる。通常・片腕段階では服と靴が戻る。
- 首の後ろは肩と頭の両方を追う厚い皮膚で接続。前屈や頭を起こす動きでも、肩の甲殻とうなじの間を塞ぐ。
- 顔の怪物化：額と頬骨を張り出させ、下顎を横と前へ拡張。くぼんだ目元と細い黄土色の目、広がった口元、短く鈍い歯を加えた。首の接続用の変形を保ち、全身変貌時は顔を前へ起こす。通常・片腕段階では元の顔へ復元する。
- 新しい皮膚は既存の骨格を共有するため、前屈・拳と足の接地を維持する。形状と衣服は進行度を戻すと復元される。共有モデルのソースは変更していない。
- 「関節位置を表示」で現在の肩・肘・手首（金）と元の肘（灰）を比較可能。
- 片腕変貌の段階ではアフロ・宇宙柄アロハ・顔・反対側の腕を維持。変形側の時計は形状確認のため非表示。

方向性の試作。変形の強さや色は確定設定ではない。診察台、攻撃判定、経路に沿った移動・追跡、本編への組み込みは含まない。
