# オープニングのシーン一覧と保存版

`/3D/exterior-scene-catalog.html` にシーン番号ごとの一覧を保存。
構図・そのシーンからの再生・全編の再生を、同じ映像プレーヤーで確認できる。
一覧では一つのiframeだけを使い、複数の3Dシーンを同時に描画しない。

## 2026-10-13の保存基準

速度変更前の確認済みコミット：`71708bd91a4553013039213646f86c76b5fe7e35`。
全1054テストとビルドの成功後に保存した。

カメラ、船の速度、カットの時間、ディゾルブのサンプラーを
`src/obs/exterior-cinematic-20261013-r1.js` に独立して保存した。
`revision=20261013-r1` でこのサンプラーを選ぶ。
保存版を変更すると復元用のリンクが変わるため、次回の保存は新しいrevisionを作る。
モデル・照明・ロゴ・ガスなどの共通アセットは同じものを使う。
それらも含めた当時のソースは上記コミットに残っている。

## 05の速度変更と戻し方

現行Bラスト案は `approach=bow&ending=underside`。
05の母艦速度だけを **2.0 → 2.1 m/s（＋5%）** に変更。
カメラ位置の軌道、画角、船の回転、小型船のドッキング時刻は維持する。
カメラの向きは進む母艦を追い、09へ切り替わらず、同じカットが続く。

一覧の「05 / Bラスト・速度変更前」で、87秒付近の停止感を直した後、
今回の速度変更を加える前の **2.0 m/s** を再生できる。
全編は一覧上部の「速度変更前の全編」から再生する。
この保存リンクは `approach=bow&ending=underside&revision=20261013-r1` を指定する。

本番のデフォルト構成と、比較用URLで選ぶ案は別。
今回保存したBラスト案は、一覧・スタディーから上記URLで選んで確認する。
