# オープニングのシーン一覧と保存版

構図・そのシーンからの再生・全編の再生を、同じ映像プレーヤーで確認できる。
一覧では一つのiframeだけを使い、複数の3Dシーンを同時に描画しない。

## 01 → 02：35秒から切り替え

## 05のカメラ終了に合わせた加速／01の上向き調整

今回の直前のカメラを `src/obs/exterior-cinematic-20261013-r2.js` に独立して保存した。
`revision=20261013-r2` は35秒からのディゾルブ・右下07・定速2.1 m/sのBラスト・上向き補正前の01を保持する。
一覧に「01 / 上向き調整前」と「05 / 加速前・2.1 m/s一定」の保存リンクを追加した。

現行05は76.5秒から始まり、カメラが移動する8秒の後半（80.5〜84.5秒）で母艦を加速させる。
カメラの減速で失われる相対速度を船の速度へ足し、移動終了後も同じ見送り速度を保つ。
通常の横長画面・core=2.6では2.1 → 7.95 m/s。縦長画面やcoreの拡大では実際のカメラ移動量に合わせて補正する。
船の座標には加速曲線を積分した距離を使い、シーク時も位置・速度が途切れない。

現行01はロゴと母艦の登場を保ち、11.4〜19.4秒に上向き1度の補正を滑らかに加える。
35秒から02へ移る時刻、船の速度、ロゴの出方は共通。

## 05：大きな移動の後、船体の高さまで上昇

最初の8秒はBの回り込みと加速を維持。その後85.5〜101.5秒の16秒でカメラを船底（Y=-52）から船体中心（Y=0）まで滑らかに上げ、横方向にも少し離す（Z=23.4→36.4、横長・core=2.6）。カメラの前後位置は固定し、母艦の加速・前進を変えず、後方から遠ざかる船を追う。101.5秒以降は同じ高さからエンドレスで見送る。

直前の低いカメラは `revision=20261013-r3` として独立保存。一覧の「上昇前・船底から加速して見送り」から確認できる。
